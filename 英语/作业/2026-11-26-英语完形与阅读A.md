# 英语完形填空与阅读 A

## 完形填空　第 44—55 题

照片拍到了选项，部分正文从纸背透出。下表结合可辨认的句子及 David Deming 的原文还原答案；试卷有改写，标有“推定”的题目仍需用完整题干核对。[完形材料原文](https://sjsu.edu/history/docs/Engineer%20Salaries%20NY%20Times.pdf)

| 题号 | 答案 | 选词依据 |
|---|---|---|
| 44 | D　demand（推定） | 原文说当下市场对某些技术的需求很大，搭配为 in high demand。照片上 D 项单词被裁切。 |
| 45 | B　while | 年长员工需要在工作中学习新技术，而年轻员工可能已经在学校学过。while 连接两种情况，表示对照。 |
| 46 | C　competition | 年轻毕业生进入职场，给年长员工带来竞争压力。 |
| 47 | B　gradually | 文科毕业生起薪较低，随后逐渐赶上理工科同龄人。 |
| 48 | A　fosters | 主语是博雅教育，宾语是解决问题、批判性思考等能力，动词应选“培养”。 |
| 49 | D　pathways | 这些能力很难量化，也很难给毕业生提供通向高薪第一份工作的明确路径。 |
| 50 | C　value | 尽管短期效果不明显，这些能力在许多职业中都有长期价值。 |
| 51 | B　However（据转折关系推定） | 前文讲理工科毕业生的工资增长，后文指出其他专业的人有时增长更快，构成转折。 |
| 52 | D　lifted | 管理、商业和法律行业的高薪岗位拉高了平均收入。 |
| 53 | A　qualities（推定） | 原文列出雇主看重的毕业生素质，包括书面沟通、解决问题和团队合作能力。 |
| 54 | C　dialogue | 后文提到师生交流和细读文本。这里指通过师生对话培养能力。 |
| 55 | A　technical | 作者提醒人们谨慎对待大学课程日益技术化、以就业为中心的趋势。 |
