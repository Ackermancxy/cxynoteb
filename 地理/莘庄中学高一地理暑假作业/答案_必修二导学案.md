### 主题 2 人口迁移

**【知识梳理】**

- 早期：交通（技术）条件限制，规模较小
- 15 世纪末到 16 世纪初：新航路开辟（航海技术）发展、交通条件改善
- 19 世纪中期至二战前：洲际（跨洲）迁移为主；欧洲流向美洲、澳大利亚、新西兰；非洲流向美洲（北美洲）；亚洲流向其他大洲
- 二战后至 20 世纪 70 年代：规模扩大（大增）；由发展中国家流向发达国家
- 国内（改革开放前）：由东部向西部（内地）、由城市向农村（边疆）迁移
- 国内（改革开放后）：由农村向城市、由内地（中西部）向沿海（东部）迁移
- 影响人口迁移的因素：自然生态环境因素、经济因素、政治因素、社会文化因素

**【同步练习 · 选择题】**

1. B　2. B　3. C　4. A　5. C　6. D　7. C　8. D　9. B　10. A

**【同步练习 · 综合分析题】**

（一）

1. 由农村流向城市，由中西部（经济欠发达地区）流向东部沿海（经济发达地区）
2. 规模大；但数量呈现减少（下降）趋势
3. 主要原因是经济因素：地区间经济发展不平衡、城乡收入差距大；农村剩余劳动力多；国家政策（户籍、就业政策）逐步放宽。
4. 对迁入地影响：提供大量劳动力，缓解用工短缺；促进第二、三产业发展和城市化；但加剧交通、住房、就业、资源环境等方面的压力，增加社会管理难度。

### 主题 3 人口容量

**【知识梳理】**

1. 自然增长、机械增长
2. 出生率、死亡率、自然增长率
3. 工业化以前：高出生率、高死亡率、低自然增长率；工业化初期：高出生率、低死亡率、高自然增长率；工业化中后期：低出生率、低死亡率、低自然增长率；后工业化时期：低出生率、低死亡率、低自然增长率（甚至负增长）
4. 性别构成、年龄构成、职业（文化）构成
5. 0–14 岁为少年儿童，15–64 岁为劳动年龄人口，65 岁及以上为老年人口
6. 人口金字塔：增长型（年轻型）—发展中国家；稳定型（成年型）；衰退型（老年型）—发达国家。引发的社会问题：老龄化、劳动力短缺、养老负担加重。
7. 资源、环境所能承受的最大人口规模和经济活动规模
8. 自然资源（首要因素）；消费水平（负相关）
9. 相对性

**【同步练习 · 选择题】**

1. ④　2. C　3. C　4. A　5. D　6. B　7. A　8. C　9. B　10. D

**【同步练习 · 综合分析题】**

（一）

1. 不均匀（不平衡）；南部人口相对稀疏，北部人口相对稠密
2. 山地（丘陵）；水资源短缺；因此资源环境承载力低（小）
3. 迁入地条件：地形平坦、水源充足、生态环境良好、有足够的土地和发展空间。
4. 积极意义：减轻人口对土地、水资源的压力，缓解人地矛盾，有利于生态环境恢复，提高资源环境承载力，从根本上实现脱贫。

## 第 3 单元 产业区位选择

### 主题 7 农业区位

**【知识梳理】**

1. 栽培植物（种植）或饲养动物（养殖）
2. 地域性
3. 因地制宜、扬长避短（充分发挥地区优势）
4. 自然因素：
   - 热量：柑橘等亚热带水果；南方地区一年两熟到三熟；东北地区一年一熟
   - 降水：南方水田农业，北方旱作农业
   - 水源：新疆绿洲（灌溉农业）
   - 土壤：酸性红壤适宜种茶树
5. 社会经济因素：
   - 市场：城郊发展蔬菜、水果、肉蛋奶及花卉
   - 交通运输：布局在交通便利（接近市场）的地方
   - 劳动力：数量和素质
   - 机械化：劳动生产率
   - 保温技术：改善热量（温度）条件

**【知识梳理 · 农业区位分析】**

1. 自然因素相对稳定，社会经济因素不断变化
2. 供不应求时价格上涨、规模扩大；供过于求时价格下跌、规模缩小
3. 自然条件
4. 市场
5. (2) 生活水平（消费水平）　(4) 转移（外流）、机械化

## 第 5 单元 环境问题与可持续发展

### 主题 13 人类面临的主要环境问题

**【知识梳理】**

一、全球变暖

- 成因：人口和经济的快速发展，化石燃料（矿物燃料）的大量使用，大气中二氧化碳等温室气体排放增多，温室效应增强
- 影响：(2) 海平面上升；(3) 降水和水循环（蒸发）现状，导致干旱、洪涝、台风、风暴潮等灾害增多

二、荒漠化

- 发生地区：干旱、半干旱地区
- 形成原因：自然因素（气候干旱、降水少、多大风）和人为因素（过度开垦、过度放牧、过度樵采、水资源不合理利用）
- 危害：(1) 农作物（粮食）减产甚至绝收；(2) 草场（草原）面积缩小、草地退化；(3) 沙尘暴（风沙）危害

三、生物多样性减少

- 类型：遗传（基因）多样性、物种多样性、生态系统多样性
- 原因：(1) 自然：物种本身的形成和灭绝、火山爆发等突发灾难；(2) 人为：掠夺式开发、环境污染带来的栖息地（生境）破坏、对生物多样性保护问题重视不足

四、环境污染

- 按环境要素：大气污染、水污染、土壤（固体废弃物）污染
- 按污染物形态：废气、废水、固体废弃物、噪声、（放射性污染）

### 主题 14 协调人地关系，走可持续发展之路

**【知识梳理】**

一、协调人地关系

- 采集—狩猎阶段：人口少；资源利用为天然食物；技术为原始技术；产业为采集、渔猎；人地关系为崇拜（依赖）自然
- 农业社会阶段：人口增多；利用农业资源；农业技术；产业为农业；人地关系为改造自然（人地矛盾初步显现）
- 工业社会阶段：人口剧增；利用矿产（不可再生）资源；工业技术；产业为工业；人地关系为征服自然（矛盾尖锐）
- 可持续发展阶段：人口合理（适度）；利用可再生（可持续利用）资源；高新技术（信息技术）；产业为绿色（可持续）产业；人地关系为协调

二、走可持续发展之路

- 由片面追求经济（GDP）增长，向经济、社会进步、资源环境持续承载相协调转变
- 过度依赖高耗能、高污染（粗放型）产业
- 各国仍面临全球变暖（气候变化）、生物多样性减少（生态破坏）等挑战
- 构建政府为主导、企业为主体、共同参与的环境治理体系
