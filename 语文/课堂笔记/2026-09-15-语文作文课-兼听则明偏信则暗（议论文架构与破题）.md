# 语文作文课：兼听则明，偏信则暗（议论文架构与破题）

> 课堂笔记 · 约 44 分钟

## 一、观点型作文的层次架构

**总论点 → 是什么 → 为什么 → 怎么做**

1. **总论点**：开头先「援引题目 + 总论点」（总论点即你的思考与立场）
2. **是什么**：界定词语/题目的**限定范围**，不是列字典，而是说明「我的观点能成立的范围」——这本身就是一个分论点
3. **为什么**：在此限定范围内观点成立的原因，含价值与意义
4. **怎么做**

## 二、分论点的三条铁律

1. 分论点**不能否定总论点**
2. 分论点**必须与总论点相关**
3. 分论点是**补充证明总论点**的

## 三、一个分论点段落的四部分

1. **分论点**（必是段落第一句）
2. **论据 + 论证方法**（举例 / 类比 / 比喻论证，论据一两句即可）
3. **论述**（重点！把论据与分论点衔接起来）
4. **总结句**（与分论点呼应）

**易错点**：

- 首句分论点写「兼听就是广泛听取意见」，末句总结写「所以兼听要审慎明辨」——两件事，思维跃迁，不可
- 论据与分论点硬接 = **强加因果**（违背充足理由律）

## 四、破题：「兼听则明，偏信则暗」

### 立场选择

名言类观点有其**合理内核**，推翻几千年名言几乎不可能 → 只能**承认合理性 + 规避局限**（加限定，不绝对化）。

### 总论点

「兼听则明**有其合理性**」（但不能绝对化，并非放之四海皆准）。

### 关键限定：兼听 ≠ 多听 / 泛听

把兼听等同于「广泛听取意见」，会被**碎片化、情绪化信息淹没**，无法理性判断 → 结果是犹豫、失误、偏激，而非「明」。

### 分论点一：听什么样的信息

真正的兼听要听**客观、理性、有数据支撑**的信息；主观、情绪化、片面的信息造成认知混乱。

四个信息源的特点与局限：

| 信息源 | 优点 | 局限 |
|---|---|---|
| 老师 / 专家 | 专业、经验足 | 可能脱离个人实际情况 |
| 家长长辈 | 为你未来考虑 | 主观期待、时代局限 |
| 学长 / 同学 | 真实、情感共鸣、代际沟通简单 | 主观化强、缺深度客观 |
| 网络平台 | 信息量大、时效强 | 专业不够、真伪难辨、情绪化 |

→ 把具体例子**抽象化为形容词**：客观 ↔ 主观、理性 ↔ 情绪化、深度全面 ↔ 片面

### 分论点二：怎么听（下节展开）

即使信息都是好的，也未必得明（如袁绍谋士给的每条路都能赢，袁绍却哪条都没走对）。
