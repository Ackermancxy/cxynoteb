# 化学作业讲评:不饱和度与同分异构体

> 2026-09-11 整理 · 一对一辅导讲评课(约 62 分钟,录音转写)
> 内容:离子浓度 · 不饱和度(新授) · 同分异构体 · 一氯代物 · 顺反异构 · 手性碳

## 一、溶液中离子浓度与水解

- **稀释不影响比值**:K 的表达式能写成 KW/KA 形式时,只稀释则比值不变
- **弱酸弱碱盐呈中性** ⇔ 阴阳离子水解程度相同 ⇔ KB = KA(如碳酸氢铵,常温 pH=7)
- **比酸性强弱**:HA 加入碳酸钠放出气体 → 酸性 HA > 碳酸 > 碳酸氢根(HA 都大于碳酸了,必然大于 HCO₃⁻)
- **水解程度(结合质子能力)**:A⁻ < HCO₃⁻ < CO₃²⁻ → 碳酸根水解更强,其盐显碱性
- **pH 排序经典题**:同浓度下 pH 由大到小:碳酸氢铵(>7)> NH₄A > 氯化铵 > 硫酸铵(C 中 NH₄⁺ 浓度大,H⁺ 更多,pH 更小)
- **抑制水解强弱辨析**:硫酸铝铵(NH₄)₂SO₄·Al₂(SO₄)₃ 中 Al³⁺ 水解呈酸性抑制 NH₄⁺ 水解;但硫酸氢铵是强酸酸式盐,**直接电离出 0.1 mol/L H⁺**,抑制程度更大
  - 答题规范:先写 c(H⁺)=0.1 mol/L,再写"该氢离子浓度比铝离子水解生成的氢离子对 NH₄⁺ 水解的抑制程度更大"

## 二、不饱和度计算(重点·新授)

**公式**(Ω,读"欧姆"状符号):

```
CxHyOz:Ω = (2X + 2 − Y) / 2
```

- **氧不参与计算**
- **卤素按氢处理**(Cl 计入 Y)
- **含氮:Y 减去氮原子数**(相当于把 N 当作"减一个 H")

例:
| 分子式 | 计算 | Ω |
|---|---|---|
| C₈H₆O₂ | (16+2−6)/2 | **6** |
| C₈H₅O₂Cl(氯按氢) | 同 C₈H₆O₂ | 6 |
| C₆H₈O₂N₂(减氮) | 同 C₆H₄O₂,(12+2−4)/2 | 5 |

## 三、常见官能团的不饱和度速查

| Ω | 官能团 |
|---|---|
| **1** | 碳碳双键、醛基(−CHO)、羧基(−COOH)、酯基(−COO−)、硝基(−NO₂)、酰胺基(−CONH−/−CONH₂)、**酮羰基**、**1 个环** |
| **2** | 碳碳三键 |
| **4** | 苯环 |
| **0** | 烷烃、羟基(−OH) |

- R = 烃基(甲基、乙基、烯基、炔基等);酰胺基中的 H 也可被 R′ 取代
- CCOH 不是基团写法,注意保证 C 四键、O 二键的稳定结构
- 大 π 键考试很少考,不用深究

## 四、同分异构体与一氯代物

**判断三板斧:**
1. **先数碳原子数**——碳数相同必不是同分异构体(直接排除)
2. **不饱和度凑数**——总 Ω 要对得上,凑不出则选项错(如 C₈H₆O₂:苯环占 4,还剩 2,两个羟基 0+0 凑不出,倒推验证)
3. **看对称性数等价氢**——对称轴一画,一氯代物种数立现

**一氯代物只有一种的典型结构**:甲烷、乙烷、新戊烷(2,2-二甲基丙烷)、环己烷、对二甲苯(苯环上一溴代物仅 1 种)

**三种二甲苯苯环一溴代物种数**:邻位 **2** 种、间位 **3** 种、对位 **1** 种 → 利用熔沸点数据分组反推结构(熔点相近的归同种二甲苯;间二甲苯对应的一溴代物有 3 种、熔点 234.2℃ 只此一种)

## 五、烃的推断套路(例:M=84)

1. 试烷烃:14n+2 = 84 → 除不尽,排除
2. 试烯烃(单双键):14n = 84 → n = 6,C₆H₁₂
3. 加条件"不使溴水褪色"(无 C=C)+ 一氯代物仅 1 种(高度对称)→ **环己烷**
4. 快速数氢:苯环(4)+ 一个环(1)→ Ω=5,C₁₄ 的 2n+2=30,减 2×5=**H₂₀**

## 六、顺反异构与手性碳

- **顺反异构条件**:必须含碳碳双键,且双键每个碳上连两个不同基团
  - 写法:双键两端各连 −CH₂CH₃ 和 −H,同侧为顺式、异侧为反式(要求写结构简式时两种都要展开写全)
- **手性碳**:连有 **4 个不同**基团的碳(如:甲基、H、OH、羧基各一 → 有手性)

## 七、书写规范(老师反复强调)

- **键线式(碳骨架)最方便**:数碳快、不易错;命名前可先把最长主链拉直重排
- 结构简式括号整体跟在**左边**原子后;左边末端写 H₃C− 更严谨
- **别乱写"间歇式/渐变式"缩合式**:容易漏碳少氢,数数麻烦
- 净水剂答题模板:铝离子水解生成 **Al(OH)₃ 胶体** → 胶体**比表面积大** → **吸附**悬浮物 → 净水(三步写全)
- 烷烃命名四字诀:**最长主链 → 近(位次最小)→ 简(简单取代基优先)→ 小(位次和最小)**
