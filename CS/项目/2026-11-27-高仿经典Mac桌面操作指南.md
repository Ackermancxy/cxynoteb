# 高仿经典 Mac 桌面操作指南

本机使用 **X11 + mlvwm 0.9.4 + macdock + picom**，桌面外观沿用 System 7 风格。快捷键中的 `Super` 指键盘上的 Windows/Command 键；`Alt` 指 Option/Alt 键。

## 常用快捷键

| 操作 | 快捷键 |
|---|---|
| 打开 Vicinae 搜索 | `Super + Space` |
| 切换窗口 | `Super + Tab` |
| 窗口缩略图总览（当前工作区） | `Super + Shift + Tab` |
| 左右平铺 | `Super + ←` / `Super + →` |
| 铺满工作区 | `Super + ↑` |
| 还原平铺前大小 | `Super + ↓` |
| 三分屏 | `Super + Shift + ←` / `→` |
| 左侧三分之二 | `Super + Shift + ↑` |
| 切换到工作区 1–4 | `Super + 1` … `4` |
| 把当前窗口移到工作区 1–4 | `Super + Shift + 1` … `4` |
| 显示/恢复桌面 | `Super + D` |
| 关闭 / 最小化窗口 | `Super + W` / `Super + M` |
| 桌面标注开关 | `Super + Alt + A` |
| 剪贴板历史 | `Super + Alt + V` |
| 打开窗口快捷键设置 | 菜单 **Special → Keyboard Shortcuts…** |

改完快捷键后，设置工具会重启 mlvwm 使更改生效。也可以按 `Alt + Escape` 重启窗口管理器。

## 窗口管理

### 边缘贴靠

拖动窗口标题栏到工作区左边或右边后松开，可平铺到半屏；拖到屏幕顶部可铺满工作区。拖动触发使用 mlvwm 内部的释放事件，因此不会和非透明拖动时的 X11 服务器抓取冲突。四分屏拖拽尚未提供，可使用已有的三分屏快捷键。

### 窗口总览

按 `Super + Shift + Tab`，或将鼠标停在默认的右上热角，可打开带缩略图的窗口总览。输入窗口标题可筛选；点击卡片可切回该窗口。总览只显示当前工作区中可见的窗口。

热角位置与动作可在 **Special → Hot Corners…** 修改。默认右上角打开窗口总览，右下角显示桌面；停留时间也可在设置窗口调整。配置文件为 `~/.config/mlvwm/hotcorners.json`，更改后守护进程会自动读取。

### 窗口组合与布局

在 **Special → Window Ops → Pair Windows…** 选择另一个可见窗口，将它与当前窗口左右平铺。配对只列出当前工作区的窗口。

在 **Special → Window Ops → Window Layouts…** 保存当前工作区布局；输入一个新名称。恢复前先切回保存时的工作区，工具会按窗口标题和窗口类匹配当前已打开的窗口。它不会替你启动已关闭的应用。布局数据保存在 `~/.config/mlvwm/layouts.json`。

## 文件操作

### 空格快速预览

在 PCManFM 中选中一个文件，按 `Space` 可打开快速预览；再按 `Space` 或 `Esc` 关闭。支持文本/代码、图片和 PDF；视频显示缩略图，并可从预览窗口启动播放器。当前文件管理器使用 `~/.local/bin/pcmanfm`。若空格无反应，确认当前进程已重启到这个本地版本，并且文件列表有焦点、只选中一个文件。

### Vicinae 文件搜索与操作

按 `Super + Space`，搜索以下脚本名称：

- **Search File Contents**：输入要查找的文字，查看命中文本和文件位置；双击结果打开文件。
- **File Actions**：输入文件名关键词，从结果中可打开文件、打开所在文件夹、改名、复制完整路径，或把项目送进传输队列。

默认搜索目录为 `~/Documents`、`~/Obsidian Vault`、`~/下载`、`~/Desktop` 和 `~/文档`；不存在的目录会自动跳过。要自定义，在 `~/.config/mlvwm/search-dirs.txt` 中每行写一个目录（可用 `~`）；文件内容搜索针对文本文件，不搜索 PDF。

如果刚安装或更新 Vicinae 脚本后搜不到命令，在 Vicinae 根搜索中运行 **Reload Script Directories**。

### 文件传输队列

打开 **Special → File Transfer Queue…**，通过 **Add Files…** 或 **Add Folder…** 加入任务，选择 **Choose Destination…**，再按 **Start Queue**。列表显示每项状态与进度；**Cancel Queue** 会停止当前任务并取消后续任务。目标已存在同名文件时会自动使用带 `(copy 2)` 的新文件名，不会静默覆盖。

选择 **Move after successful copy** 时会先提示确认；只有复制成功后才删除源项目。目录和符号链接也可排队处理。

### 废纸篓、批量改名和截图

这些工具位于 **Special** 菜单：

- **Trash…**：查看、恢复废纸篓项目；恢复前会检查目标是否已存在。清空废纸篓有二次确认。
- **Batch Rename…**：批量调整文件名。
- **Screenshot…**：全屏、当前窗口或选择区域截图；可保存或复制。
- **Disks and Devices…**：查看磁盘与可移动设备。

## 桌面标注与媒体控制

### 桌面标注

按 `Super + Alt + A`，或选择 **Special → Annotate Desktop**，显示透明绘图层。按 `Esc` 退出；按 `1`–`4` 切换颜色，`+` / `-` 改变线宽，右键拖动擦除，`Z` 撤销，`C` 清除，按 `S` 或回车保存。PNG 保存到 `~/Pictures/Annotations/`。

### 媒体控制

菜单栏时钟左侧会显示媒体状态和曲名。左键播放/暂停，中键上一首，右键下一首。需要播放器提供 MPRIS 控制接口；没有播放器时显示 `Media`。

## 故障排查和维护

- **工作区快捷键**：按 `Super + 1`–`4` 切换；若窗口移动到了别的工作区，用 `Super + Shift + 1`–`4` 移回。
- **预览未更新**：关闭 PCManFM 窗口后重新打开；本地版本在 `~/.local/bin/pcmanfm`，源码补丁在 `~/arch-mlvwm/src/pcmanfm-space-preview.patch`。
- **mlvwm 源码重建**：在终端运行 `~/arch-mlvwm/rebuild`。边缘贴靠补丁位于 `~/arch-mlvwm/src/mlvwm-edge-snap.patch`，并已登记到 `patches.series`。
- **菜单、快捷键配置**：主要文件为 `~/.mlvwm/.mlvwmrc`、`~/.mlvwm/MenuBar`、`~/.mlvwm/VirtualDesktops` 和 `~/.mlvwm/themes/System7`。
- **开机启动**：热角和标注守护进程由 `~/.xinitrc` 在登录时启动；不需要 Wayland 或 Plasma。
- **重建配置归档**：`~/arch-mlvwm/src/mlvwmrc-master.zip`。此次更新前的备份在 `~/.local/state/mlvwm/selected-features/mlvwmrc-master.zip.before-selected-features`。

本机系统变更记忆见 `~/SYSTEM-CHANGES.md`；本指南同时保存在 Obsidian Vault 和本机笔记库 `CS/项目/`。
